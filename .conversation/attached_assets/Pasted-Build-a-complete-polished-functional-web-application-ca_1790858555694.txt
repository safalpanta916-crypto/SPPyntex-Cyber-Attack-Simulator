Build a complete, polished, functional web application called:

SPPyntex Cyber Attack Simulator

Created and designed by Safal Panta.

The project should feel like a personal cybersecurity learning laboratory — not a corporate security product, not a generic SaaS dashboard, and not an obviously AI-generated template.

The visual identity should feel consistent with the existing SPPyntex Security Laboratory project.

The main idea is simple:

Let users safely experience common cybersecurity attack scenarios through interactive simulations, make decisions during those scenarios, see what could happen, and learn how the attack can be prevented.

This is an educational simulator.

It must NOT perform real attacks against real systems.

==================================================
CORE IDEA
=========

The user chooses a cybersecurity scenario.

Example:

Phishing
Password Attack
Brute-force
Man-in-the-Middle
SQL Injection
Malware Behavior

The application then presents a fictional situation.

The user reads the situation, makes a decision, and the simulation responds to that decision.

The user should be able to see:

What happened
Why the decision mattered
What the attacker was trying to achieve
What warning signs existed
What defensive measure could stop or reduce the attack

The experience should feel interactive and educational rather than like reading a textbook.

==================================================
IMPORTANT SAFETY REQUIREMENT
============================

Everything must be simulated.

Do NOT implement:

* Real credential attacks
* Real brute-force attempts
* Real SQL injection against external systems
* Real network interception
* Real malware execution
* Real exploitation of websites
* Unauthorized scanning
* Credential harvesting
* Persistence
* Real-world attack automation
* Password cracking against real credentials

Use fictional data, local application state, diagrams, animations, and predetermined educational outcomes.

No external target should ever be attacked.
