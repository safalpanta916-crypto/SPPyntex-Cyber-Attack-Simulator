# SPPyntex Cyber Attack Simulator

An interactive cybersecurity learning project created by Safal Panta to help users understand common cyber attack scenarios through safe simulations.

## Project

SPPyntex Cyber Attack Simulator is a browser-based educational simulator.

Users can explore fictional cybersecurity scenarios, make decisions during simulations, see different outcomes, and learn how defensive measures can reduce risk.

The project is designed for learning only. It does not perform attacks against real systems.

## Main Features

* Interactive attack simulations
* Phishing scenario
* Password attack scenario
* Brute-force scenario
* Man-in-the-Middle scenario
* SQL injection scenario
* Malware behavior scenario
* Decision-based outcomes
* Simulation scoring
* Attack-flow visualizations
* Defensive recommendations
* Cybersecurity learning concepts
* Local progress tracking

## Technology

* TypeScript
* React
* Vite
* Tailwind CSS
* pnpm
* Modern browser APIs

## Project Structure

The project is organized around the application interface, reusable components, simulation scenarios, learning content, and supporting configuration.

The main source of truth for simulation behavior should remain inside the application's scenario and simulation logic rather than being duplicated in UI components.

## Design Direction

SPPyntex uses a dark, technical, personal visual identity.

The interface should feel:

* Clean
* Interactive
* Technical
* Modern
* Personal
* Slightly experimental

Avoid making the project look like a generic corporate cybersecurity dashboard or an AI-generated SaaS template.

## Safety

This project is intentionally designed as a safe educational simulation.

It does not:

* Attack real systems
* Perform real login attempts
* Harvest credentials
* Execute malware
* Intercept real network traffic
* Perform unauthorized scanning
* Target real databases
* Automate real-world attacks

All attack scenarios use fictional data and simulated outcomes.
